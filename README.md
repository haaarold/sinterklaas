# Sinterklaas & Ozosnel: Pakjesavond!

Een speelbaar browserspel in één HTML-bestand. Sinterklaas rijdt op Ozosnel over de daken en bezorgt pakjes. Bij gouden schoorstenen wacht een reken- of taalopdracht voor groep 3.

Open `index.html` in de browser om te spelen.

- Spatie of tikken: springen
- Pijltje omlaag of knop "Gooi pakje": pakje gooien
